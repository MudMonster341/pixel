# Feedback

Dev feedback from playing the game, created with the in-game overlay (dev mode, press `` ` ``).

- `items/FB-0001.json`: one file per item: what, where (map, position, pointed-at tile), game
  state, conversation thread and status history
- `screenshots/FB-0001.jpg`: what the screen looked like, with the pointed-at spot circled

Don't edit these by hand. The owner uses the overlay; the agent uses `npm run feedback`.
The full workflow is in [docs/FEEDBACK.md](../docs/FEEDBACK.md).
